# Wireframes — services/web 핵심 4화면

> Phase 2 (Domain Skeleton) ~ Phase 4 (List/Preview/Download) 가 참조할 레이아웃 reference.

표기 규약:
- `[btn]` = 버튼/액션
- `( )` = 입력 필드
- `<...>` = features 슬라이스 (Phase 3+)
- 모든 fixed/sticky 요소는 `--spacing-safe-*` 적용

## 1. /drive — 메인 화면

### 1.1 모바일 (≤ 768)

```
┌──────────────────────────────┐ ← safe-area-top
│ [☰] Drive          [🔍] [👤] │ ← navbar (sticky)
├──────────────────────────────┤
│  내 드라이브 / 사진           │ ← breadcrumb
├──────────────────────────────┤
│  ┌────────────────────────┐  │
│  │ 📷 photo-001.jpg       │  │ ← <features/file-preview>
│  │ 2.4 MB · 5분 전        │  │   (탭 → preview)
│  └────────────────────────┘  │
│  ┌────────────────────────┐  │
│  │ 📷 photo-002.jpg       │  │
│  │ 1.8 MB · 12분 전       │  │
│  └────────────────────────┘  │
│        (스크롤)               │
├──────────────────────────────┤
│              [+]             │ ← FAB <features/file-upload>
├──────────────────────────────┤ ← safe-area-bottom
└──────────────────────────────┘

[☰] 탭 → drawer (headlessui Dialog):
  ┌─────────────┐
  │ Drive       │
  │   내 드라이브│
  │   휴지통    │
  │ ─────────── │
  │ [👤] Me     │
  └─────────────┘
  ※ "최근/즐겨찾기" 제거 (PRD Won't)
```

영역: navbar / breadcrumb / list / FAB / drawer-sidebar.
features: `<file-preview>` (탭), `<file-upload>` (FAB), `<file-download>` (preview 내).

## 3. /drive → upload-flow

### 3.1 모바일 (FAB 탭 시작)

```
1. FAB [+] 탭
       ↓
2. ┌──────────────────────────────┐
   │  무엇을 올릴까요?            │ ← bottom-sheet (Dialog)
   │  ┌──────────────────────┐   │
   │  │ 📷 카메라             │   │ ← Capacitor 카메라
   │  │ 🖼 갤러리             │   │ ← <input type="file" accept="image/*">
   │  │ 📄 파일               │   │ ← <input type="file">
   │  └──────────────────────┘   │
   └──────────────────────────────┘
       ↓ 선택
3. ┌──────────────────────────────┐
   │ photo-001.jpg                │
   │ 2.4 MB                       │
   │ ████████░░░░ 64%             │ ← 진행률 (accent)
   │ [취소]                       │
   └──────────────────────────────┘
       ↓ 완료
4. ┌──────────────────────────────┐
   │ ✓ 업로드 완료                │ ← toast (success)
   └──────────────────────────────┘
       ↓
5. drive list 최상단 표시
```

features: `<file-upload>` (api/mutation + model/useUploadFile + ui/UploadButton + ui/UploadProgress).

### 3.2 데스크톱

toolbar 의 [+ 업로드] 탭 → 동일 dialog → 진행률은 toolbar 하단 inline bar.

## 5. MVP one-liner 추적

PRD MVP: "모바일에서 사진 1장 업로드 → PC 웹의 드라이브 목록에 5초 이내 노출 + 인라인 미리보기 + 다운로드".

본 와이어프레임 추적:
1. **모바일 §3.1** — FAB → 갤러리 → 진행률 → toast
2. **데스크톱 §1.2** — drive list 최상단 자동 표시 (TanStack Query invalidation)
3. **데스크톱 §4.2** — 행 클릭 → inline preview → [⬇] 다운로드

완전 추적 가능. ✓
